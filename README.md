# Connectory

An editorial index of Model Context Protocol (MCP) servers: verified setup snippets, auth/scopes, a config builder for Claude Desktop, Cursor, VS Code and generic `mcp.json`, guides, and drift detection.

**Live:** https://connectory-rose.vercel.app

## Stack
- Next.js 15 (App Router, mostly static) + TypeScript
- Self-hosted fonts (`next/font/local`), `next/og` for the OG image
- `@vercel/blob` for submissions and newsletter signups, `@vercel/analytics`
- Logos: `simple-icons` (generated by `scripts/gen-logos.mjs`) plus local PNGs in `public/logos/`

## Develop
```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

## Add a connector
1. Add an entry to `data/connectors.json` (slug, name, category, description, repo/docs URL, `setup` snippets copied from official docs, `auth: { method, scopes }`, `lastVerified: "YYYY-MM-DD"`). Use only facts you've checked against the source. If you can't verify something, mark it "see README" or "Not documented".
2. Add a logo mapping in `data/logos.json` (a simple-icons slug or a PNG in `public/logos/`). If there's no logo, a monogram is shown.
3. Run the drift check to record a baseline (below), then build.

## Drift detection
```bash
node scripts/check-drift.mjs
```
This fetches each connector's README or docs, hashes the setup-relevant lines, compares them with `data/drift.json`, and flags changes. Flagged connectors get a "Needs re-verification" badge and appear on `/status`.

## Deploy
The site is deployed to Vercel (project `connectory`). This repo is **not** connected to Vercel; deployments are made separately. Environment variables (set in Vercel and never committed):
- `BLOB_READ_WRITE_TOKEN`: Vercel Blob storage
- `ADMIN_TOKEN`: Bearer token for `/api/admin/*` (subscriber CSV export)
- `GOOGLE_SITE_VERIFICATION`: Search Console meta tag (optional)
